# 打不开或显示异常

先看现象属于哪一类,再按对应的一节处理。大部分情况你自己就能解决。

## 一、跳回登录页,或提示没有权限

助手界面跟随你所在组织的统一登录。登录状态过期后,再打开就会跳回登录页。

**怎么办**:重新登录一次。登录后回到助手页面即可,之前的会话记录不会丢。

如果登录成功但仍然提示没有权限,说明你的账号还没有被开通助手。**联系你所在组织的管理员**。

## 二、页面一片空白

浏览器把页面打开了,但内容是空的。

界面本身带有自恢复机制:首次渲染没有完成时,会出现一个纯 HTML 的恢复面板。

- 面板显示**正在加载**时,说明前端资源还在下载中,**等一下**即可
- 加载结束仍未渲染,面板会提示重新载入。**继续等待**会取消这次重载、给当前页面更多时间;**重试**会立即重新载入

如果反复出现,按下面的顺序排查,每做一步后点一次**重试**:

1. **停用会注入所有网页的浏览器扩展**。这是最常见的原因 —— 某些扩展会在页面脚本执行前介入,导致前端应用无法启动。广告拦截、脚本管理、翻译类扩展尤其值得先关掉试试。
2. **换一个无痕窗口,或换一个浏览器**。可以快速区分是扩展/配置问题还是页面本身的问题。
3. **强制刷新一次**,清掉浏览器缓存的旧版页面资源。Windows 用 `Ctrl + F5`,macOS 用 `Cmd + Shift + R`。

三步都试过仍然空白,到第四节。

## 三、能打开,但界面元素错乱或功能点不动

通常是浏览器还在用缓存里的旧版界面资源。按上一节的第 3 步**强制刷新**。

仍然不对的话,清除该站点的浏览数据后重新登录。

## 四、提示助手不可用,或长时间没有响应

每位员工的助手是一个独立运行的后台实例。它可能正在维护窗口内重启,或者暂时不可用。

**怎么办**:先等几分钟再刷新。如果持续不可用,**联系你所在组织的管理员** —— 这一类问题需要在管理端处理,你这边没有可操作的开关。

反馈时带上这几条,会快很多:

- 出现问题的**大致时间**
- 你看到的**原话**(截图最好)
- 你做了什么操作之后出现的
- 第二节的三步里,你已经试过哪些

## 什么时候该找管理员

以下情况不用自己继续排查,直接找管理员:

- 登录成功但提示没有权限
- 提示助手不可用,且等待后仍未恢复
- 第二节三步做完仍然空白
- 你能打开,但同组同事打不开(或反过来)
