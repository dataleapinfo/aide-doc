# 实验室功能

设置里的**实验室**页收着一批**可以开、但还在试验阶段**的功能。它们是开放给你的 —— 想用就可以打开,只是需要先知道「试验阶段」意味着什么。

## 试验阶段意味着什么

- **行为可能变**。同一个功能在下一个版本里表现不一样,是正常的。
- **可能更慢或更贵**。有些功能会让助手做更多轮思考、调更多工具。
- **出问题的排查支持有限**。遇到异常,先关掉再试一次,通常就恢复了。

不影响的是:**数据访问的权限和留痕不会因为开了实验功能而放宽**。这条在任何模式下都一样。

## 有哪些

**代码模式** —— 让助手用写代码的方式完成任务,而不是一步步调用工具。处理批量、重复的活儿更利索。

**多助手协作** —— 把一个大任务拆给多个助手并行做,再汇总。任务够大时明显更快,小任务反而是负担。

**工具检索** —— 可用工具很多时,让助手先检索再挑,而不是把整份清单都读一遍。可以省下不少上下文。

**循环检测** —— 察觉助手在原地打转时打断它。开着通常没坏处。

**隔离工作区** —— 给助手一份独立的工作副本,改动不会碰到你的正式内容,确认没问题再合回去。

**云端工作环境** —— 把执行放到一个独立环境里跑。这一项**当前还没有接通**,详见[尚未开放的能力](/not-yet-open)。

## 建议怎么用

一次只开一个,用几天看看。同时开一堆,出了问题分不清是哪个引起的。

觉得某一项确实好用,**跟管理员说一声** —— 试验功能转成默认开启,靠的就是这类反馈。
