# 记忆

## 没有隐藏状态

助手的记忆就是一组 Markdown 文件。它写进去,下次开会话时读出来。

**模型只记得写进文件的东西。** 没有另一套你看不见的记忆 —— 你没让它记的,它下次就是不知道。

想让它记住什么,直接说:「记住我们的报表口径是自然月」。它自己决定写到哪个文件。

## 四个文件

| 文件 | 放什么 |
|---|---|
| `USER.md` | 关于你的稳定偏好 —— 你的角色、常用口径、希望它怎么跟你说话 |
| `MEMORY.md` | 长期事实和决定 |
| `memory/<日期>.md` | 当天的笔记和上下文 |
| `DREAMS.md` | 自动整理留下的记录,给人看的 |

在设置的**记忆**页可以直接看和改这些文件。改错了就改回来,它读的就是文件本身,没有别的地方需要同步。

## 自动整理

助手会定期把短期笔记里反复出现的东西提升成长期记忆,顺手清掉过期的。这个过程在后台跑,跑完在 `DREAMS.md` 留一份可读的记录,你可以回去看它这次改了什么、为什么。

**跑的时间由管理员统一设定,每个人的时间点是错开的** —— 不是所有人同一时刻一起跑。你在设置里看到这个频率但改不了,原因见[由管理员配置的部分](/admin-managed)。

自动整理只往 `MEMORY.md` 里加东西。它不会去动你手写的内容,除非明确判断某条已经被新的取代了 —— 而那种情况会记在 `DREAMS.md` 里。

## 记忆搜索不出网

记忆的检索用的是**本地全文索引**,没有接任何向量化服务。

这不是省事,是刻意的:配了向量检索就意味着要把记忆内容发给外部的嵌入模型。**你记在这里的东西不会因为「搜索」离开这套环境。**

索引用的是三元组切分。中文没有词边界,按词切会漏,三元组正是为此选的 —— 所以中文检索是好使的,不需要你刻意用英文记。

## 记忆和会话的区别

[会话](/sessions)是一次对话的完整内容,删掉就没了。记忆是从对话里沉淀下来、跨会话生效的东西。

删会话不会删记忆。反过来,清掉记忆文件里的某条,之前那段对话里说过的话还在会话历史里。
