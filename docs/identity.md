# 身份与个人资料

## 登录走公司统一身份

你不需要为助手单独注册账号,也没有单独的密码。进来的时候用的就是你在公司的那个身份。

这意味着两件事:公司那边停掉你的账号,这边同时就进不来了;反过来,你也不用再记一套密码。

## 每个人的助手是独立的

这套部署里,**每位员工有自己独立的助手实例** —— 不是大家共用一个。

你的会话、记忆、模型选择、各项设置,都只属于你。别人看不到,你也看不到别人的。

所以界面里凡是涉及「多个人共用一个实例」的说明 —— 谁能看到谁的会话、怎么分配角色之类 —— 在这里都用不上。

## 个人资料页能改什么

**设置 → 个人资料**里可以改显示名和头像。就这些,它只影响界面上怎么称呼你。

## GitHub 那一行为什么是空的

个人资料里有一行 **GitHub 账号**,你会发现它是空的,而且点不动。

**这不是坏了。** 那个功能的前提是用 GitHub 登录,底座才能确认这个 GitHub 账号确实是你。我们走的是公司统一身份,不经过 GitHub —— 拿不到,也不会去拿。

跟它绑在一起的那些功能(比如在提交记录里署你的名)同样不生效。

## 权限不在这一页

个人资料页不决定你能做什么。

**你能查到哪些数据,由数据平台的权限决定** —— 按你在组织里的实际授权算,和助手这边的显示名、头像、角色标签都没有关系。想多查一些,走数据平台那边的申请流程,不是在这里改。
