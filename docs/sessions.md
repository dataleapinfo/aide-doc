# 会话与助手

## 会话就是一次对话

你和助手的每一轮对话叫一个**会话**。会话不存在浏览器里,存在服务端 —— 所以关掉标签页、换台电脑、换个浏览器登录,之前聊的都还在。

设置里的**会话**页列出你所有的会话,可以回去翻,也可以删掉不想留的。

删掉会话会同时删掉这段对话的内容。助手已经写进[记忆](/memory)的东西不受影响 —— 那是另一套东西,在另一个地方。

## 什么时候该开新会话

换个话题就开新的。一个会话拖得越长,里面塞的无关上下文越多,助手越容易被前面的内容带偏,也越慢越贵。

反过来,**需要接着之前的进度继续**时,就回到原来那个会话,不要重开 —— 助手看得到这个会话里说过的一切,不需要你再复述一遍。

## 「助手」这个设置页

设置里还有一个**助手**页。底座支持在一个实例里配多个互相隔离的助手,各自有各自的工作目录和对话历史。

你大概率用不到它 —— 默认就一个,够用。

真要配的话,有件事得先知道:**单个助手上的工作目录、沙箱、可用工具这几项,配了也会被清掉**。这几项由管理员在整个实例的层面统一决定,不接受逐个助手覆盖。

原因不是图省事。沙箱是这套部署里助手与其他一切之间**唯一的隔离边界**,在某一个助手上开个口子,这个边界对整个实例就不成立了。所以它不是「默认值可以改」,而是「不接受改」。

其余的设置照常。详见[由管理员配置的部分](/admin-managed)。

## 会议记录

设置里的**会议**页需要接通会议平台才能抓记录,当前部署没有接。见[尚未开放的能力](/not-yet-open)。
