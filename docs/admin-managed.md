# 由管理员配置的部分

设置里有一部分页面,你能打开、能看到当前状态,但**改不了**,或者改了不生效。这不是故障。

## 为什么

助手的运行配置由**管理端统一下发并持续校准**。这样做有三个目的:

- 每位员工拿到的是一致、可预期的环境,不会因为改错一个开关就用不了
- 安全与治理相关的设置不能由使用者自行关闭
- 出问题时管理员能快速定位,不必先排查「这台是不是被改过」

所以即使某个开关在界面上是可见的,真正生效的值也以管理端为准 —— 你改了会在下一次校准时被改回去。

## 哪些属于这一类

| 设置区域 | 说明 |
|---|---|
| 连接与网络 | 助手实例的访问方式、地址、代理 |
| 安全 | 权限模式、访问控制 |
| 审计 | 操作留痕的开关与范围 |
| 密钥与凭据 | 共享密钥、外部服务凭据 |
| 插件 | 启用哪些插件、插件的参数 |
| 版本与更新 | 助手底座的版本升级 |
| 基础配置 | 配置文件本身及其参考项 |

**版本升级尤其注意**:界面里可能出现「有新版本可用,是否升级?」这类提示。**请不要按它**,也不必转告 —— 升级由管理端统一安排、经审批后执行,不走这条入口。

## 你自己能改的

- **模型选择** —— 在管理员允许的范围内,你可以挑自己习惯的
- **外观** —— 主题、语言等纯界面偏好
- **你自己的会话与记忆** —— 属于你个人的内容,别人看不到,你可以自行整理

## 需要改动时怎么办

**联系你所在组织的管理员**,说明:

- 你想达成什么(不是「请打开 X 开关」,而是「我需要做 Y」)
- 你在哪个页面看到的
- 这件事对你的工作有什么影响

按目的提会比按开关提更快 —— 很多需求有别的、已经开放的实现路径。
