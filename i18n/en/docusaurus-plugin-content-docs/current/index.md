## About this documentation

The assistant runs on a general-purpose agent substrate, so part of what you see in the interface comes with that substrate and is **not necessarily enabled** in your organization's deployment. The job of this documentation is to say plainly which features you can use, which your administrator manages, and which are not open yet.

The substrate's open-source notice is on the [credits page](/credits).
